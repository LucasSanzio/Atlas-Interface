Decisões do projeto

Interface
Reaproveitar a esfera, os projetos em órbita e o chat redimensionável do HTML original. Substituir as simulações por dados reais.
Integração
Usar a arquitetura do Codex WebUI como referência. Um serviço em Node.js inicia o Codex App Server e repassa os eventos ao navegador.
Conta
Usar o login do ChatGPT gerenciado pelo Codex, dentro do acesso e dos limites do plano.
Conversas
Usar o histórico acessível ao App Server e validar quais conversas existentes podem ser retomadas no Windows.
Aprovações
Mostrar o pedido no chat de origem e guardar a decisão e o resultado para consulta após reiniciar.
Execução
Rodar na máquina local e usar o projeto aberto como diretório de trabalho, seguindo a política de permissões do Codex.
